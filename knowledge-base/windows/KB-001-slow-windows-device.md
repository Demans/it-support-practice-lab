# KB-001 — Slow Windows device

## Symptoms
Slow sign-in, delayed application launch, freezing, or sustained high resource usage.

## L1 workflow
1. Confirm whether one app or the whole device is affected.
2. Ask when the issue began and what changed.
3. Check CPU, memory, disk, and startup impact in Task Manager.
4. Confirm adequate free storage.
5. Apply pending approved updates and restart if appropriate.
6. Test again using the same measurable action.

## Escalate when
- Storage or memory errors appear.
- Performance degrades again after basic remediation.
- Several endpoints are affected.
- A system service or security control requires administrative change.

Use fictional or sanitized evidence only.
