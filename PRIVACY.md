# Privacy and safety

This public repository is for simulated IT-support training only.

## Never commit

- Passwords, API keys, tokens, certificates, private keys, or recovery codes
- Real names, email addresses, phone numbers, addresses, or customer records
- Device serial numbers, asset tags, license keys, or private inventory data
- Real internal hostnames, IP plans, VPN details, or configuration exports
- Unsanitized logs, screenshots, email contents, or chat transcripts

## Safe practice

Use clearly fictional users, systems, domains, identifiers, and errors. Prefer mock screenshots. If a source artifact came from a real environment, do not publish it until every identifying or sensitive element has been removed and reviewed.
