# INC-002 — External monitor not detected

- Support level: L1
- Status: Resolved
- Priority: P3
- Environment: Fictional Windows 11 laptop and USB-C dock

## Report
A second display showed no signal after the laptop returned from sleep.

## Checks performed
1. Confirmed monitor power and selected input.
2. Reseated the display and dock cables.
3. Used Windows display detection.
4. Tested a known-good fictional cable.
5. Power-cycled the dock and monitor.

## Resolution
The monitor was detected after the dock power cycle and cable reseat. No hardware replacement was required.
