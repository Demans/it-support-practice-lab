# INC-001 — Windows laptop running slowly

- Support level: L1
- Status: Resolved
- Priority: P3
- Environment: Fictional Windows 11 laptop
- Simulated user: Alex Example

## Report
The laptop became slow after sign-in. Opening the browser and file explorer took more than 30 seconds.

## Checks performed
1. Confirmed the slowdown affected several applications.
2. Reviewed Task Manager and found a fictional sync process using high CPU.
3. Checked free storage and startup applications.
4. Restarted the simulated sync process and disabled an unnecessary startup item.
5. Rebooted and repeated the timing test.

## Resolution
Application launch time returned to the fictional baseline. The simulated user confirmed normal performance.

## Learning points
Start with scope, resource use, storage, recent changes, and safe reversible actions.
