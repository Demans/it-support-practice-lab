# Screenshot rules

Only add mock or fully sanitized screenshots.

Before committing an image, remove or replace:
- Names, email addresses, photos, and message content
- Passwords, tokens, recovery codes, and QR codes
- Serial numbers, asset tags, license keys, and device IDs
- Internal hostnames, IP addresses, tenant names, and office locations
- Browser tabs, bookmarks, notifications, and unrelated desktop content

When possible, recreate the relevant screen with fictional data instead of redacting a real screenshot.
